# 查看与保存课件

- **实时课件** 入课后查看老师展示的课件，可跟随教师翻页或手动刷新。[课堂重连](classroom-reconnect.md)
- **历史课件** 在「动态」打开课堂记录，从课堂详情进入原版历史课件。显示范围以当前账号获得的页面为准。[动态与课件缓存](activity-cache.md)
- **单页保存** 点击图片打开全屏预览，可左右切换和双指缩放，长按后选择保存当前页。
- **批量导出** 点击「下载课件」并选择图片版 PPTX 或图片 ZIP，再通过系统选择保存位置。PPTX 以图片保留页面外观。

历史课件图片加载失败时，可点「刷新课件」重新获取图片地址。
