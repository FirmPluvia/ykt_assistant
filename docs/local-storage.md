# 本地课堂凭证

## 保存位置与隔离

优先使用 `Android/data/<包名>/files/classrooms/<兼容存储代次>-<作用域哈希>.bin`，系统未提供外部应用目录时使用内部私有目录。成功 checkin 同时返回 HTTP Bearer 和 WebSocket lessonToken 后保存；二者仍由 Android Keystore 独立 AES-GCM 密钥加密。服务器域名、账号 user_id、课堂 lessonId 和兼容旧文件的存储代次参与作用域与认证附加数据，文件名不暴露账号和课堂 ID。

退出只撤销当前缓存客户端的运行期租约；同账号重新登录或重启后可再次读取原文件，其他账号 / 服务器 / 课堂不能复用。旧客户端在撤销后不能继续恢复凭证或写入新的有效缓存，后台加密中的迟到写入会被拒绝。

## 永久保留规则

- 移除 24 小时本地期限；时间经过多年或设备时钟回退，不影响本地读取。
- 下课事件不删除凭证。
- HTTP 401 / 403、WebSocket 401 / 403 或 1008 不删除磁盘凭证；当前连接仍会停止使用被拒绝的认证。在本次账号会话内，对被拒绝的同一 HTTP 凭证不反复自动恢复，用户确认重新签到后可覆盖保存新凭证。
- 解密失败、数据损坏或字段不匹配时不恢复，也不自动删除文件。重新成功入课可覆盖同一作用域的旧文件。
- 退出账号清除当前账号 Cookie 及其保存的账号记录、撤销运行期客户端并清理动态缓存，但保留各账号的加密课堂凭证。
- 没有定期课堂凭证清理任务。清除应用数据、卸载、系统存储被外部删除或 Keystore 密钥丢失仍会导致数据不可用；已被旧版本删除的文件无法恢复。

“永久保存”只指本地保存期限，不能延长雨课堂服务端凭证的有效期，也不改变课程权限或签到要求。

## 入课流程

重启后先恢复账号。点击同一课堂或输入课堂 ID 时，后台读取同账号 / 同服务器 / 同课堂的本机凭证，快速命中直接连接，不显示读取弹窗；超过 500ms 才显示可取消提示。缓存缺失或本次会话已被服务端拒绝时询问是否签到并进入课堂，只有用户确认才发送 checkin，不通过动态报告推断签到，不自动补签。

Cookie 与课堂凭证分开保存：Cookie 仍为内部私有目录明文，见 [Cookie 管理](cookie-login.md)。

## 验证

模拟测试覆盖多年和时钟回退后恢复、退出 / 重启后按账号恢复、跨账号隔离、迟到写入拒绝、损坏文件保留、HTTP 拒绝和下课后文件保留、HTTP / WebSocket 认证及不自动重签。加密文件测试使用真实 AES-GCM 与测试密钥，真实 Android Keystore 与服务端有效性仍需设备联调。

## AI 配置

独立 `ai_settings` SharedPreferences 保存接口、模型与选项；API Key 由 Android Keystore AES-GCM 加密后保存。配置跨雨课堂账号共用，退出账号不清除，可在 AI 设置中清除。请求和响应不写入日志。

## 同步偏好

`request_sync` 内部 SharedPreferences 按当前账号保存同步签到 / 答题开关、账号范围、主观题独立编辑选项与同步结果提示方式，不保存额外 Cookie 或答案。首次开关关闭、范围为同服务器全部其他账号；退出后不会据此派发请求，重新登录同账号可恢复偏好。

## 答案图片

系统选择器授予临时读取权限，重编码图片及上传 URL 仅在当前课堂草稿内存中保存，不额外写入相册或持久化答案缓存。新轮次清空图片；移除草稿引用不删除图床对象。
