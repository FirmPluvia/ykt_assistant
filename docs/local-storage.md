# 本地课堂凭证（2.7.4）

优先使用 Android 应用专属目录，不申请共享存储权限：

- 凭证：Android/data/com.ykt.assistant/files/classrooms/<注销代次>-<作用域哈希>.bin
- 系统未提供外部应用目录时使用内部私有目录。目录写入失败时保留内存凭证，并提示下次需要重新入课。Android 对其他应用访问 Android/data 的限制由系统决定。

## 课堂凭证

成功 checkin 同时返回 HTTP Bearer 与 WebSocket lessonToken 后保存。两个 token 使用 Android Keystore 生成的独立 AES-GCM 密钥加密；服务器域名、账号 user_id、课堂 lessonId 和注销代次参与作用域与认证附加数据。文件不包含明文 token，文件名不暴露账号 / 课堂 ID。

重启 App 后先恢复账号并获取课程；用户点击同一正在上课的课程时，在后台静默读取匹配缓存，快速命中直接连接 WebSocket，不显示读取弹窗；超过 500ms 才显示可取消的等待提示。切换页面、返回或注销会取消待显示提示并拒绝迟到入课，不发送 checkin 或课堂报告查询。已有内存凭证时也直接复用。缓存缺失或不可用时仅询问是否签到并进入课堂，只有用户确认才发送 checkin；不请求动态报告来推断签到。取消读取后不安装缓存凭证或连接课堂，不会在启动时自动对课程签到。

缓存最多用于保存后 24 小时内的自动恢复；实际有效期由雨课堂决定。过期、时钟回退或加密校验失败的文件在读取时删除。课堂 HTTP 返回 401 / 403，WebSocket 握手返回 401 / 403、明确返回该认证错误码或关闭码 1008 时，删除对应缓存并提示从首页重新进入；临时断网不当成凭证过期。收到明确下课事件时删除磁盘缓存，保留当前进程已加载页面供阅读。

退出账号立即推进持久化注销代次，旧客户端不能再读取或写入有效缓存，再于后台清理旧文件。进程退出只关闭连接，保留缓存。跨账号、跨服务器、跨课堂不会复用凭证；Cookie 仍由现有 SessionVault 在内部私有目录加密保存。

保存失败不把已成功入课改判为签到失败，而是提示下次需要重新入课。服务端明确拒绝缓存时不会偷偷重发签到，请用户重新选择课堂完成入课流程。没有承诺缓存能绕过服务端过期、扫码或课堂权限要求。

## 旧版文件清理

2.7.3 移除了本地日志功能与界面。升级启动后只清理旧版应用专属 logs 目录，符号链接不跟随；不会删除 files/classrooms 中的课堂凭证。清理在后台执行，失败时下次启动重试，无额外页面提示。

## 验证边界

测试覆盖加密保存 / 新实例恢复、账号 / 服务器 / 课堂隔离、过期与损坏、注销与迟到写入、HTTP / WebSocket 凭证恢复、服务端拒绝后的失效处理、UI 恢复不发签到请求、旧版目录清理不影响课堂凭证。加密文件测试使用真实 AES-GCM 与测试密钥，生产密钥使用 Android Keystore；真机 Keystore、目录权限与雨课堂凭证有效期仍需设备联调。
