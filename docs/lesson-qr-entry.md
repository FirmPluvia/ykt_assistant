# 扫码入课

登录后首页提供并排的“使用课堂 ID 入课”和“扫码入课”。打开扫码页时请求相机权限，使用本机 ZXing 相机预览与二维码解码；不上传相机画面、不保存二维码截图，不打开扫描得到的网页。后台或关闭扫码页停止相机，重复回调只接受一次。

## 支持内容

- 1～20 位、非全零的数字课堂 ID，按字符串处理，避免长数字丢精度。
- 当前雨课堂服务器 HTTPS 地址中唯一、有效的 lessonId / lesson_id / lessonid 查询参数。
- `/api/v3/lesson/check-in/` 下的官方签到地址（包括动态二维码），以及 `/v/lesson/`、`/m/v2/lesson/`、`/lesson/` 的课堂入口，交由官方 scan 接口解析。未带直接课堂 ID 的其他路径暂不猜测。

只接受标准 / 荷塘 / 长江 / 黄河的已知服务主机。二维码属于不同服务器时提示切换对应账号；登录 / 微信授权二维码、第三方地址、HTTP、非默认端口、带用户名密码的 URL 及歧义 ID 均拒绝。courseId / classroomId 不当作 lessonId，路径末尾的任意数字也不猜作课堂 ID。

## 官方动态解析

动态签到地址无论是否含 lessonId，都先使用当前账号 Cookie 调用 `POST /api/v3/app/scan`，JSON 为 `{ "url": "<扫描的完整原始 URL>" }`。参数顺序、签名及编码按原值保留，不重建签名、不去掉有效期。返回 data.value 必须是有效数字课堂 ID。

取得 ID 后沿用普通入课：同账号 / 同服务器的本机凭证命中则复用；没有凭证时显示课堂 ID 并确认是否签到，只有确认后调用 checkin。解析失败、二维码过期、无权限或用户取消时不创建课堂凭证，不偷偷签到。扫码期间账号变更或退出，旧结果会被拒绝。

扫码解析仅校验当前账号。其他账号的入课仍使用各自会话，不共享当前账号的扫码校验或课堂 token；特殊二维码、课程权限和位置签到要求仍由服务端决定。

## 权限与设备

相机声明为可选能力，没有相机也能安装应用并使用其余功能。拒绝权限时显示说明，允许重试或到系统设置授权，也可关闭改用课堂 ID。扫码页不需要存储、定位、麦克风或相册权限。相机预览、真实机型旋转 / 对焦、真实学校二维码仍需真机联调；本次验证为二维码解析、接口模拟、权限 / 生命周期与入课回归测试。

## 账号管理对齐

“当前”和“切换”在右侧同一操作列，使用相同字体、内边距、背景及 48dp × 44dp 尺寸；当前状态不响应点击。账号名称不再因当前标签占据标题行而错位。

## 扫码页控制

关闭使用与应用一致的浅绿圆角按钮，保持至少 44dp 点击高度。关闭 / 系统返回会取消扫码并停止相机；已成功识别时的迟到关闭或解码回调不会覆盖结果。

相机预览启动后读取实际的 isZoomSupported、zoomRatios 和 maxZoom。支持时提供“－ / ＋”、滑杆和倍率按钮，并可在取景区双指缩放；倍率按钮恢复该相机的默认最小倍率。范围和显示倍率来自当前相机，不假设所有设备支持固定 2× / 3×。

变焦通过相机参数 setZoom 在相机线程上执行，因此预览和二维码解码收到同一放大后的帧，不是仅把屏幕 View 拉大。小幅连续手势会累计，避免粗粒度设备上双指操作不生效。手势 / 滑杆变化合并到约 32ms 一次，设备范围外的输入钳制到边界。

当前功能控制所选镜头的驱动变焦，通常为数码变焦，不声称切换光学镜头。暂停、关闭、相机错误和销毁时撤销待执行更新，迟到能力回调按相机会话隔离。不支持或未返回有效参数时隐藏控件，继续正常扫码。

测试覆盖非线性倍率映射、边界、无效设备数据、连续细小手势、按钮和复位、后台 / 关闭后的回调隔离；真实对焦和不同机型相机驱动仍需真机验证。

## 点击对焦

默认优先选择设备支持的连续拍照对焦，其次连续视频对焦；仅支持普通自动对焦的设备按间隔重新对焦，固定焦距设备继续扫码。点击取景区时，将显示坐标按实际预览裁切、旋转和前置镜像映射到相机对焦区域，再请求一次自动对焦。支持时也设置测光区域。

对焦框以白色表示正在对焦、浅绿色表示驱动报告成功、浅橙色表示可重新点击尝试。约 1.8 秒后清除框并恢复原自动对焦模式及区域；无回调也按时恢复。不支持指定区域 / 自动对焦的设备提示并保留原扫码能力，不显示虚假的成功状态。

连续点击会使旧回调和旧恢复任务失效；双指缩放不触发点击对焦。后台、关闭、相机故障或销毁后停止对焦任务并丢弃迟到回调。硬件调用与变焦、预览操作使用同一相机线程，解码画面继续来自原摄像头。

验证覆盖传感器坐标转换、裁切 / 旋转 / 镜像、边界、对焦优先级、重复点击、超时恢复、固定焦距降级及生命周期回调隔离。模拟相机测试不代表已验证真机对焦精度。
