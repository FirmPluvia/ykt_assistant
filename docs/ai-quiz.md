# AI 答题辅助

在“我的 → AI 答题 → 配置 AI”填写兼容 OpenAI Chat Completions 的 HTTPS 接口、模型名称与 API Key。可填写 Base URL（例如 `https://example.com/v1`）或完整 `/chat/completions` 地址；不接受 HTTP、URL 内账号密码、查询参数与片段。Key 可留空以使用无需认证的接口，已有 Key 时输入框保持空白，保存空白表示保留原 Key，可通过“清除 AI 配置”一起删除。

Key 使用 Android Keystore 的 AES-GCM 加密后写入内部私有 SharedPreferences，其他配置明文保存，不与雨课堂账号绑定。退出雨课堂不会清除 AI 配置；可在设置中单独清除。真实设备 Keystore 与第三方接口需自行验证。

## 使用

打开实时课堂中的“课堂答题”，选中正在开放的题目，点击“AI 分析”。默认先预览建议和简要解析，再点击“填入答案”；填入后隐藏该按钮。也可直接点击底部强调样式的“提交”，先填入分析结果再提交；超时仍需二次确认。可开启“分析后自动填入”，自动填入只修改草稿，仍需自己点击提交。支持单选、多选、投票、填空、主观题文字与判断题，其他题型只读。

默认发送题干和选项；可选择附带当前题目课件图片，图片在本机缩放为最长边 1280 像素的 JPEG 后内联发送，不暴露课件签名 URL。不发送雨课堂 Cookie、课堂凭证、账号 / 课堂 ID 或原有答题草稿。题目及图片会发送给所配置服务商，AI 结果可能错误，填入前请核对。

固定系统提示词要求模型仅输出 JSON，并将题目内容视为数据，忽略其中指令。默认始终发送 `response_format: {"type":"json_object"}`，不再提供开关；接口和模型需支持 JSON 模式。固定系统提示词与严格结果校验也始终有效。无论失败与否均不自动重试或切换服务商，修改配置后可重新分析。

## JSON 契约

```json
{
  "schema_version": 1,
  "question_token": "请求中提供的本次随机令牌",
  "problem_type": 1,
  "status": "answered",
  "answer": {"option_keys": ["A"], "blank_values": [], "text": ""},
  "explanation": "简短解题依据",
  "confidence": 0.9
}
```

- `problem_type`：1 单选、2 多选、3 投票、4 填空、5 主观题、6 判断题（单个原始选项键）。
- 选择题使用请求中的选项键，不能按选项位置猜测；单选仅一项，多选不得重复，投票不超过允许数量。
- 填空使用 `blank_values`，数量必须与空格数一致；主观题使用 `text`。不适用字段必须为空。
- `status` 为 `answered`、`uncertain` 或 `unsupported`；后两者答案必须为空且不能填入。
- 客户端校验字段类型、令牌、题型、选项、空格数和 0～1 的置信度；拒绝截断、混杂说明或非法 JSON，仅兼容完整外层 Markdown JSON 代码围栏。

题目内容、轮次、开放状态或 AI 配置变化时中止分析；关闭面板 / 返回后台会取消请求。迟到结果不会写入另一题，自动填入还会检查草稿是否变化。填入不会触发提交接口，AI 分析仅填入当前题目草稿；AI 页提供同样的同步复选框与账号修改，点击提交沿用统一同步链路；主观题需先逐账号编辑确认。

## 验证与边界

协议、HTTP 请求隔离、失败响应脱敏、Key 加密保存、取消、轮次变化和界面填入通过模拟服务测试。未提供真实模型 Key，尚未完成实际服务商或课堂联调。完整演示包仅生成标记为模拟的本机 JSON 响应，不具备真实推理能力。
