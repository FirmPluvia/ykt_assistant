# 同步请求

只有保存多个账号且当前已登录时，才显示“我的 → 同步请求 → 同步设置”、课堂的同步签到，以及答题 / AI 分析页的同步答题。单账号不显示这些入口；User-Agent、Cookie 等独立设置保留。

同步签到、同步答题的开关首次默认关闭，选择账号默认是同服务器的全部其他账号。点击旁边“修改账号（数量）”调整范围。开关和选择按当前账号保存；签到与答题各自保存账号范围，主观题沿用答题范围。未修改的全选会包含后来新增的同服务器账号，已移除账号自动过滤。

## 签到

入课确认卡片先设置“同步签到”，点击签到入课后先处理当前账号，成功进入课堂后依次处理所选其他账号。当前账号已缓存凭证时，进入课堂仍按同步设置处理其他账号。课件页也有同样的复选框，主动勾选或在开启状态修改账号时会处理所选账号。

其他账号分别校验自身 Cookie，优先复用自身课堂凭证，没有凭证才签到。独立请求不并发，不切换当前登录。关闭进度卡片停止后续账号，已发生的签到无法撤回。仅刷新课件或重绘页面不会自动重复发起签到。

## 答题

普通答题卡片和 AI 分析卡片共用开关及账号选择。勾选同步后点击“提交答案”或 AI 页“提交”，先提交当前账号，明确成功后再按顺序提交所选其他账号；当前账号失败或结果不明确，不发送其他账号。

单选、多选、判断、投票、填空使用本次提交时冻结的当前答案。主观题也使用同一同步开关，“主观题分别编辑答案”默认关闭；开启后先为每个目标账号填写独立文字（初始为空），逐项预览并确认，才开始当前账号和其他账号提交。不会自动生成不同答案；可在设置中关闭独立编辑，改为复用当前文字。

各目标账号使用自己的 Cookie 和本堂课凭证，重新获取题目并核对题干、题型、选项、填空数量与投票限制。答题不会自动签到。缺少凭证时提示先开启同步签到入课。失败不影响其他账号成功，本题本轮在本机成功的账号禁止再次发送；进度卡片可重新选择失败账号重试，需自行核对网络不明确的官方记录。

教师延时会使用最新时限，答案仍取提交时草稿。确认后跨过截止时间不会静默改用补交，需要重新确认。原有补交二次确认、换轮检查、身份和内容校验继续有效。关闭答题卡片、换账号、离开课堂或进入后台会取消后续同步，返回前台不会自动补发；已经发送的请求可能到达服务端。

全部验证使用模拟账号和接口，尚未进行真实学校课堂联调。

主观题图片：可纯图片作答，其他账号使用同批选择，但以自己的会话独立上传。独立编辑只区分文字，图片预览 / 移除在当前账号答题面板进行。详见 [答案图片与直接 AI 填入](answer-images.md)。

## 结果提示与按钮

同步设置新增“同步签到与答题结果使用卡片提示”，默认不选中，按当前账号保存。不选中时不弹同步进度 / 结果卡片，结束时 Toast 显示“本次同步签到成功 x 条，失败 x 条”或答题同类汇总；仅统计其他账号返回的结果，不把当前账号计入。普通答题、AI 提交及主观题同步共用此设置；必要的主观题编辑和补交确认仍保留。关闭答题或换题后不弹迟到的同步 Toast。

所有应用原生按钮去除 elevation / translationZ 与状态阴影动画；固定尺寸按钮根据空间适配文字大小和换行，不使用显示省略号。长题目选择器允许自然增高，避免强制固定行高裁切。窄屏、较大字体与长标签通过布局测试；官方验证网页内控件仍由官方页面绘制。

## 默认开关与位置同步

所有同步设置开关首次默认关闭：同步签到、同步答题、主观题独立编辑、结果卡片。账号选择仍默认同服务器全部其他账号；已手动保存的开关不强制重置。

位置签到卡片提供“同步位置签到”及“修改账号”，沿用同步签到开关 / 范围。当前账号明确签到成功后，顺序查询各账号自身状态，已确认跳过，未确认时校验会话、课堂凭证、目标坐标与签到会话，使用各自本轮信息提交当前卡片所选坐标。没有凭证不自动入课。当前账号已签到且接口仍返回可校验目标时，可直接为其他账号操作，不重复提交当前账号。

已提交但未确认的状态不算成功，同一界面会话内不会重复发送。卡片 / Toast 模式同样适用于位置同步，汇总不包含当前账号；失败数包含未取得明确成功确认的账号。取消、后台、换课或轮次变化会停止后续操作；已发送请求不能撤回。真实课堂尚未联调。
