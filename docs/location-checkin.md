# 服务端位置签到

根据前述约定重新实现，默认采用雨课堂返回的签到中心坐标，允许用户修改提交经纬度，不读取手机 GPS / 网络定位，已删除精确和大致定位权限。该坐标代表服务端签到位置，不是手机实测位置。只处理当前已进入的课堂，保留用户确认，不自动批量签到。

## 流程

GET `/api/v3/lesson/location-checkin/eligibility` 查询状态，携带当前课堂 Bearer。已签到直接提示；未开始、已结束、状态不完整或缺少坐标时不提交。未签到且可用时显示坐标和地址，点击“确认位置签到”后重新查询资格与目标，原默认目标仍匹配才按用户选择的坐标 POST `/api/v3/lesson/location-checkin/submit`。

提交字段：用户选择的 lat、lng、当前 lessonId、source=54、服务端 address。POST 的 code=0 只表示接受提交，再次查询返回 signed=true 才提示签到成功；否则保留“刷新状态”和等待确认提示。

## 数据和保护

优先读取 session.centerLat / centerLng，其次完整的 lat / lng，最后读取当前课堂 locationcheckinext 事件中的 centerLat / centerLng。支持 data 包装、数值字符串；每个来源必须是完整坐标对，拒绝跨来源拼接、空值、布尔值、NaN、Infinity 或越界值。

提交串行化并绑定课堂 ID / Bearer / 轮次；发生换课、结束、新轮次或坐标变化时旧确认失效。本轮相同目标 POST 成功后只查状态，即使后续查询失败也不自动重复提交。位置 POST 客户端关闭连接失败自动重试。

locationcheckinext 只提示开启，不直接提交；locationcheckinend 或下课使旧事件失效并关闭旧确认。重连、退出会清除内存状态。

测试覆盖坐标来源、非法数据、提交字段、已签到跳过、轮次 / 换课失效、防重复、确认失败、查询失败恢复、注销隔离及无定位权限。测试不访问真实课堂，最终状态仍以雨课堂接口为准。

## 自定义与随机坐标

位置卡片的纬度、经度输入框默认填入课堂返回坐标。手动输入必须为有限数字，纬度在 [-90,90]、经度在 [-180,180]；无效值在本地提示，不查询或提交。小按钮“随机 50 米”以原默认坐标为中心，按球面距离生成圆盘内随机点；不会沿上一次结果累积偏移。“恢复默认”恢复两个输入框。随机计算保留少量舍入余量，避免六位小数显示后超过 50 米。

确认后固定本次用户选定坐标并禁用编辑。重查服务端默认目标、签到轮次及课堂凭证，只有原目标未改变才发送自定义 lat/lng。用于防重复的键仍由原默认目标与轮次组成，更改输入不产生新轮次。address 仍为服务端参考地址，不额外调用地图逆地理编码，不读取手机 GPS；是否接受所选坐标由雨课堂决定。坐标编辑与随机本身不会发起签到。

## 长按设置随机距离

长按随机按钮打开距离设置，支持 1～10000 米（可含小数）。默认 50 米，保存到本机偏好设置后更新按钮与“恢复默认”左侧的长按提示。每次随机仍以服务端默认坐标为中心；恢复默认只恢复经纬度，不重置所选随机距离。保存或取消距离均不发起签到。签到弹窗关闭、轮次变化或账号退出会使旧距离设置失效并关闭子弹窗；提交期间不可编辑。

## 位置签到同步

多个已保存账号时，卡片新增“同步位置签到”和修改账号入口，共用同步签到范围。首次默认关闭；当前账号确认成功后，按顺序为所选账号查询和提交本卡片坐标。各账号使用自己的会话与已有课堂凭证，不自动入课，已确认状态跳过，目标 / 会话不一致拒绝提交。当前账号已签到且接口仍返回有效目标时，可只同步其他账号。若接口缺少可校验目标，则不猜测坐标或轮次。

结果遵循卡片 / Toast 设置，默认 Toast。已提交未确认不会算作成功，同一界面会话内不会重复发送；未提供跨进程的待确认提交缓存，重开后应核对官方记录。取消、后台、换课堂或轮次变化停止后续操作。
