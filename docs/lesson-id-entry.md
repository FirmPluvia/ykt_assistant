# 课堂 ID 与手动入课

正在上课的课程卡片提供“复制课堂 ID”，仅复制 `lessonId`，不包含账号 Cookie、HTTP Bearer 或 WebSocket 凭证。未上课的课程不显示复制按钮。

登录后，首页可点击“使用课堂 ID 入课”，输入 1～20 位非全零数字 ID。ID 全程使用字符串，避免长数字精度丢失；不接受二维码 URL、课程 ID 或班级 ID。课程 ID / 班级 ID 也可能是数字，客户端无法仅凭格式判断，请确认来源。

如果 ID 对应本机已保存的同账号、同服务器课堂凭证，直接复用；无凭证时显示课堂 ID 并询问“是否签到并进入课堂？”，确认前不发送签到请求。确认后调用 `POST /api/v3/lesson/checkin`，发送 `source=21`、字符串 `lessonId`、`joinIfNotIn=true`，保存返回的两种课堂凭证并建立 WebSocket。

手动入课使用当前登录账号和当前服务器，不接受他人的凭证。知道 ID 不代表具有访问权限，服务端拒绝、课堂结束、动态二维码或位置签到要求仍需按官方规则处理。失败时保留错误和重试入口，不显示入课成功。

此功能保留原有下载互斥、账号隔离、取消和防重复提交机制。手动输入的 ID 若与首页列表匹配，使用已有课程名称；否则显示“课堂 <ID>”。

首页还提供并排的“扫码入课”，扫描后取得课堂 ID 并复用相同确认流程，见[扫码入课](lesson-qr-entry.md)。
