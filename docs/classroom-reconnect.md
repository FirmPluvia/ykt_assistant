# 课堂重连

前台实时课堂页每 5 秒检查连接。断连且没有正在连接的请求时重新建立课堂 WebSocket，仍使用原课堂凭证，不调用入课签到接口。已连接 / 连接中不重复发起；位置签到提交中跳过当次检查以免打断其轮次校验。物理断网由 WebSocket 失败 / 关闭或心跳超时识别，不宣称能立即检测所有网络中断。

离开实时课堂页、进入后台、退出、销毁、下课或凭证失效时停止新增自动重试；返回课堂页 / 前台重新启用检查。停止重试不会主动断开原本健康的连接。连接握手在途时等待其成功或超时，不每 5 秒创建平行请求。

勾选跟随教师时，连接健康则立即使用最新已知教师页码；已断连则重连，待 hello / 翻页事件返回后再跟随，不先跳到断连前缓存的旧页码。重连若发现课件已切换，获取新课件后同步页码。同一课堂内多次重连的旧回调按尝试序号拒绝，不覆盖当前课堂状态。

验证覆盖 5 秒间隔、重复渲染、健康连接、连接在途、跟随重连后新页码、旧回调、切页、前后台、下课及失效凭证。模拟连接测试不代表真实移动网络环境验证。
