# 主观题图片与独立 AI 填入

主观题中点击“添加答案图片”，通过系统文档选择器选择图片；不申请相册全量读取权限。选中后立即上传，可在提交前预览和移除。最多 6 张，原始文件最多 16 MB；本机校正方向、缩放至最长边 2048，白底重编码为 JPEG（最多 4 MB），不上传原始文件名或 EXIF 元数据。可只提交图片，或文字与图片一起提交。视频暂不支持。

上传分两步：当前账号 Cookie 向 `/pc/generate_qiniu_token` 请求 `cms-attachment` 凭证，然后向 `https://upload.qiniup.com/` 发 multipart。外部上传只带七牛 token 和图片，不带雨课堂 Cookie、课堂 Bearer 或账号头；使用配置的 User-Agent。验证成功后构造 `result.pics` 中的 `pic` 和 `thumb` URL。兼容七牛 `{key,hash}` 以及带 `success:true` 的响应，明确失败 / 错误 key 不接受，不自动重放上传。

图片上传期间禁止提交，显示图片序号进度；上传失败保留原有草稿和已完成图片，可重新选图。关闭、返回后台或题目变化时取消上传，并丢弃迟到响应。上传和答题提交是两个动作；移除只从本题草稿去掉引用，未提供图床删除接口，已上传资源可能继续存在。

开启同步答题后，各账号使用同批所选图片，但以自己的登录会话分别获取 token 并上传，不借用当前账号的图床 URL。主观题独立编辑只区分文字，图片共用选择；某账号上传失败会跳过其提交并继续下一个。上传耗时跨过时限时，保留原有补交确认保护。

其他账号主观题编辑框下的“AI 分析”按钮会发起新分析，等待后直接填入文字，不弹分析结果卡片，不自动提交。使用“我的”AI 配置与严格 JSON 校验，可反复点击；失败保留旧文字，关闭或换轮丢弃迟到结果。图片开关仍表示附带题目的课件图片，不会把答案草稿图片自动发送给 AI；不保证多次生成的文字必然不同。

测试使用本地 HTTP 服务、模拟 AI 和系统选择器回调；真实学校上传权限、七牛授权和课堂评分仍需真实账号联调。
